# バグ修正チェックリスト

調査日: 2026-07-17

`pnpm typecheck`、全ユニットテスト、プロダクションビルド、主要画面・API の静的調査を基準に、再現可能な機能不良・認可不備・ブラウザ上の不整合を列挙する。チェックは修正実装と回帰確認の両方が完了した時点で付ける。

## 認証・通信

- [x] アクセストークン期限切れ時、チャット・論点生成・学習計画 AI・目次取込のストリーミング通信だけがトークン更新を経由せず 401 で失敗する
- [x] OAuth コールバックが JWT の Base64URL 形式を通常の Base64 としてデコードし、有効なトークンでもログイン完了に失敗する場合がある
- [x] Google OAuth で `email_verified` を確認せず、未確認メールを既存アカウントへ自動リンクできる
- [x] 未ログインでも `Cmd/Ctrl+K` からグローバル検索を開け、保護 API への不要な 401 リクエストが発生する
- [x] 学習計画一覧・計画詳細・演習一覧にルートガードがなく、未ログイン時に画面描画後の保護 API エラーになる
- [x] 不正な `Origin` ヘッダーで CORS 判定中の `new URL()` が例外を投げ、API が 500 を返す
- [x] AI 系エンドポイントの一部がレート制限のパスマッチから漏れている

## 画像・チャット

- [x] 認証必須の画像 URL を `<img src>` に直接指定しているため、チャット添付画像と演習画像が 401 になり表示されない
- [x] 画像アップロード完了後も DB のファイルサイズが `0` のままで、画像メタデータ API が誤った値を返す
- [x] WebP 判定が `RIFF` の4バイトしか見ず、WAV/AVI 等を WebP 画像として受理できる
- [x] チャット送信時の `imageId` の存在・所有者を検証せず、別ユーザーの画像 ID をメッセージへ紐付けられる
- [x] 画像・演習プレビューの Object URL を再選択時・アンマウント時に解放せず、長時間利用でメモリリークする

## 演習

- [x] 演習確定で「理解済み」を選んでも論点の学習進捗とチェック履歴が更新されない
- [x] 演習確定時に選択論点の所有者を検証せず、別ユーザーの論点を紐付けられる
- [x] 演習完了後の「論点を見る」が選択論点ではなく常にホームへ遷移する
- [x] 解析完了時に React のレンダー中に状態更新しており、再レンダー警告や不安定な画面遷移の原因になる
- [x] 演習候補の検索・AI 推薦に削除済み論点が混入し得る

## 復習・検索・ナビゲーション

- [x] 復習画面の「セッション数」「良い質問数」条件が API に送られず、良い質問数も常に 0 と表示される
- [x] 「最終チャットから N 日以上」が最終アクセス日時に対する逆向きの条件になっており、対象論点を誤る
- [x] 検索・復習・ノート・最近の論点からのリンクが学習ドメイン ID を保持せず、別ドメインまたは存在しない URL へ遷移する
- [x] 旧 `/subjects/...` URL の互換リダイレクトが既定ドメインを固定使用し、追加ドメインの教材を誤った URL へ送る
- [x] 学習ドメイン配下を表示中でもサイドバーの「学習」が選択状態にならない

## 学習計画・クイックチャット

- [x] 学習計画の項目・改訂更新 API が子 ID を計画 ID で絞らず、別ユーザーの項目や改訂を更新・削除できる
- [x] 学習計画の科目 ID・項目の論点 ID に対する所有者検証がなく、別ユーザーの教材を参照できる
- [x] クイックチャットで同名論点があると、作成した論点ではなく別カテゴリの同名論点へ遷移することがある
- [x] クイックチャットが存在しない・別ユーザーの学習ドメインでも AI 呼び出しを実行してしまう

## 品質・回帰

- [x] メトリクス Hook のテストが React の `act(...)` 警告を出し、実際の状態更新警告を見落としやすい
- [x] 修正後の型検査、全ユニットテスト、プロダクションビルド、API スモークテスト、実ブラウザ操作を完了する
